Security

The file holds the recovery phrase, encrypted with a separate password (not the PIN), and the wallet's creation date, so restoring from it scans only blocks after that date. Keep the file and the password apart.

Node

searching…

The node sees which blocks and transactions the wallet requests and your IP address, but not your keys. node.bytecoin.community is run by the Bytecoin community; node01/node02 are run by the original Bytecoin developers. All three allow CORS, so they work directly from the browser. node01/node02 do not share their pool of unconfirmed transactions: through them an incoming payment appears once it is in a block (≈2 min).
